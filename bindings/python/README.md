# Rhythm units: Python bindings

Python bindings for [rhythm-units](https://github.com/chethandvg/rhythm-units), built from the Rust core with PyO3 and maturin. Function names and results are identical to the Rust crate; the shared golden vectors prove it in CI.

```bash
pip install "git+https://github.com/chethandvg/rhythm-units@v0.1.0#subdirectory=bindings/python"
```
